# ML Coffee CLI releases

Official binary downloads and signed CLI + managed Skill release manifests for [ML Coffee](https://getmlcoffee.com/).

This repository contains distribution artifacts and release documentation. Application source code is maintained separately and remains proprietary.

Public download promotion is being prepared. Use the [official download page](https://getmlcoffee.com/download) to check availability; draft releases are not installable public releases.

Published executables are paired with their embedded ML Coffee Skill. Initial installation verifies version-specific checksums served by the official website before execution; subsequent compatible updates verify the signed release manifest and activate the pair atomically. Changes to permissions, sensitive data scope or compatibility authority still require consent.

Installing a CLI, previewing an order or generating a QR code does not authorize a wallet payment. Payment is confirmed by the user in their wallet. Current acceptance uses a controlled supplier fixture and does not establish physical delivery or real merchant receipt.
